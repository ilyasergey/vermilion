# Vermilion execution plans

This directory is the implementation repository's authoritative planning area.
It ports the staged plan from the `verus-lean-planning` planning repository
and records implementation status against that plan.

- [Execution plan](execution-plan.md): stages, gates, sequencing, and current status.
- [Incremental computation](incremental-computation.md): future architecture for
  edit-local VC regeneration and proof checking.

Research background remains in the planning repository; actionable work and
completion claims belong here, next to the implementation and its logs.
